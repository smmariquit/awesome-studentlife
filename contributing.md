# Contribution Guidelines

## What belongs here

- A public or open-source tool for campus navigation, scheduling, student services, or student communities.
- A working project with a link to the product, source, or maintainer.
- A description that states the student task it supports.

## What does not belong

- Student discounts, software offers, or course-resource directories.
- Generic tools with no student or campus use case.
- Landing pages with no usable product.
- AI-generated link dumps.

## Pull request checklist

- [ ] Link works.
- [ ] Description explains the student or campus task it supports.
- [ ] Entry is in the right section and alphabetical order.
- [ ] No duplicate already exists.

## Description style

Bad:

> A powerful platform for improving student life.

Good:

> Open-source indoor navigation service with support for multi-building campus maps.
